# BigFileFinder

一个轻量、高效的Windows大文件查找工具，帮助你快速定位占用磁盘空间的大文件，轻松释放存储空间。

## ✨ 核心功能

- 📂 **灵活的扫描范围**：支持选择磁盘驱动器或任意文件夹
- 🎛️ **精准过滤**：可自定义文件大小阈值（MB），支持按文件类型筛选/排除
- 📊 **实时扫描进度**：直观展示扫描路径、文件数量、耗时和预估剩余时间
- 📋 **清晰的结果展示**：表格形式呈现文件路径、大小、修改日期等信息，支持列排序
- 📤 **结果导出**：可将扫描结果导出为CSV/TXT格式
- 🖱️ **便捷操作**：右键打开文件位置、安全删除文件（二次确认）
- ⚡ **高性能**：多线程扫描，避免界面卡顿，高效处理海量文件
- 🛡️ **稳定可靠**：优雅处理访问权限、编码问题等异常，避免程序崩溃

## 📋 系统要求

- **Python版本**：Python 3.8 及以上
##  运行程序
```python
python main.py
```
## 使用指南
选择扫描路径：点击路径选择按钮，选择要扫描的磁盘 / 文件夹

### 设置筛选条件：

输入文件大小阈值（例如：100 表示扫描大于 100MB 的文件）

开始扫描：点击「开始扫描」按钮，查看实时进度

查看结果：扫描完成后，在表格中查看大文件列表，可点击列标题排序

### 操作文件：
右键文件 → 「打开文件位置」：直接跳转到文件所在文件夹

右键文件 → 「删除文件」：二次确认后删除文件（谨慎操作）

导出结果：点击「导出结果」按钮，选择 CSV/TXT 格式保存
